# MasterGo MCP Skill

用于在 Codex 中连接并操作 MasterGo Vibe MCP 画布的 skill。

## 内容

- `mastergo-mcp/SKILL.md`：skill 主说明
- `mastergo-mcp/scripts/setup-mastergo-mcp.sh`：配置 Codex Desktop 和通用 MCP 客户端的辅助脚本
- `mastergo-mcp/agents/openai.yaml`：skill 显示信息与默认提示词

## 安装

将 `mastergo-mcp` 目录安装到 Codex skills 目录，或使用 Codex 的 GitHub skill 安装流程，并将路径指定为 `mastergo-mcp`。

安装后，在 Codex 中提到 MasterGo、MCP 或画布操作即可触发此 skill。
